# Kıta Yazılım Odoo Addons

Bu repoda, Kıta Yazılım tarafından geliştirilen Odoo eklentileri (addons) yer almaktadır. Her bir eklenti, Odoo platformunu daha işlevsel ve kullanıcı dostu hale getirmek için tasarlanmıştır.

## Hakkımızda
Kıta Yazılım, Odoo üzerinde uzmanlaşmış, yenilikçi ve güvenilir çözümler sunan bir yazılım firmasıdır. Müşterilerimizin iş süreçlerini dijitalleştirerek verimliliklerini artırmayı hedefliyoruz.

## Eklentiler
Aşağıda bu repoda bulunan Odoo eklentilerinin kısa açıklamalarını bulabilirsiniz:

### 1. payment_paytr_kt
PayTR ödeme altyapısı ile Odoo'nun entegre çalışmasını sağlar. Online ödeme işlemlerini kolaylaştırır.

### 2. pos_order_reciept_balance_kt
POS fişlerinde bakiye bilgisinin gösterilmesini sağlar. Müşterilere daha şeffaf bilgi sunar.

### 3. pos_receipt_category_totals_kt
POS fişlerinde kategori bazlı toplamların gösterilmesini sağlar. Satış analizini kolaylaştırır.

### 4. sequence_dynamic_placeholders
Odoo'daki sıralama (sequence) yapısına dinamik placeholder desteği ekler. Esnek numaralandırma imkanı sunar.

## Kurulum
1. Bu repoyu klonlayın:
   ```bash
   git clone https://github.com/kitayazilim/odoo-addons.git
   ```
2. İlgili addon klasörünü Odoo'nun `addons` dizinine ekleyin.
3. Odoo arayüzünden uygulamayı yükleyin.
