POS Receipt Category and UoM Quantities
==================================

ENGLISH
-------

Description:
------------
This Odoo module adds product category and unit of measure (UoM) quantities to the POS (Point of Sale) receipt. It is useful for businesses that want to display category totals and UoM-based quantities directly on the printed or electronic POS receipt.

Features:
---------
- Shows product category on the POS receipt
- Displays total quantities by unit of measure (UoM)
- Seamless integration with Odoo POS

Requirements:
-------------
- Odoo 16, 17, 18
- point_of_sale module

Installation:
-------------
1. Copy the module to your Odoo addons directory.
2. Update the app list and install POS Receipt Category and UoM Quantities.

Usage:
------
- When a POS order is completed, the receipt will display product categories and UoM totals for the order lines.


------------------------------


TÜRKÇE
------

Açıklama:
---------
Bu Odoo modülü, ürün kategorisini ve birim bazında (UoM) miktarları POS (Satış Noktası) fişine ekler. Özellikle kategori toplamlarını ve birim bazında miktarları POS fişinde göstermek isteyen işletmeler için faydalıdır.

Özellikler:
----------
- POS fişinde ürün kategorisini gösterir
- Birim (UoM) bazında toplam miktarları gösterir
- Odoo POS ile tam uyumlu çalışır

Gereksinimler:
--------------
- Odoo 16, 17, 18
- point_of_sale modülü

Kurulum:
--------
1. Modülü Odoo eklenti dizininize kopyalayın.
2. Uygulama listesini güncelleyip POS Receipt Category and UoM Quantities modülünü yükleyin.

Kullanım:
--------
- POS siparişi tamamlandığında, fişte ürün kategorileri ve birim toplamları görüntülenir.
